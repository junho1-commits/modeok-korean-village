우리말 한옥마을 모험 — 교사용 구글 점수 기록 연결

기록장과 Apps Script 프로젝트의 비공개 주소는 교사가 별도로 보관합니다.
아래 순서는 다른 시트로 옮기거나 새로 설치할 때 사용합니다.

1. 점수 기록용 시트를 소유 계정으로 엽니다. 시트 공유는 비공개로 유지합니다.
2. 확장 프로그램 → Apps Script를 엽니다.
3. 기본 Code.gs 내용을 google-apps-script/Code.gs 파일의 내용으로 바꾸고 저장합니다.
4. 함수 목록에서 setup을 선택해 실행하고, 이 점수 기록 프로그램의 구글 시트 접근을 허용합니다.
5. 배포 → 새 배포 → 유형 선택 → 웹 앱을 선택합니다.
   실행 사용자: 나(시트 소유자)
   액세스할 수 있는 사용자: 모든 사용자
   학생은 구글 로그인 없이 점수만 제출하며, 기록장 내용은 읽을 수 없습니다.
   학교 관리자가 외부 웹 앱을 차단했다면 이 설정을 사용할 수 없습니다.
6. 배포 후 /exec로 끝나는 웹 앱 URL을 score-config.js의 endpoint에 넣습니다.
7. 수정한 게임 파일을 학생용 GitHub Pages에 업로드합니다.
8. 학생용 주소에서 테스트 이름으로 미션 하나를 마쳐 실제 시트에 한 행이 생기는지 확인합니다.

기록 항목:
기록 시각, 학생 이름, 미션, 정답 수, 전체 문제 수, 100점 환산 점수,
통과 여부, 정식 도전/회복 복습/자유 복습, 도장 수, 선택 관문 수,
남은 라이프, 완주 여부, 풀이 시각, 여행·도전·기록 식별자.

같은 도전 결과를 다시 보내도 기록 ID로 중복을 막습니다.
전송 대기 기록은 새 여행을 시작해도 이전 학생의 이름과 함께 보존합니다.
미션별 완료 결과만 전송하며 개별 문항 답안은 전송하지 않습니다.
인터넷이 끊겼다면 같은 브라우저에서 다시 열거나 '기록 다시 저장'을 누릅니다.
시트에 실제로 저장된 확인을 받기 전에는 저장 완료라고 표시하지 않습니다.
브라우저 저장 공간을 사용할 수 없다는 표시가 나오면 확인될 때까지 창을 닫지 마세요.

이전 별명 여행은 이름을 한 번 확인한 후 이어 갑니다.
이름을 확인하기 전에 끝낸 과거 결과는 새 이름으로 소급 전송하지 않습니다.
공용 기기에서는 학생이 바뀔 때 '새 여행'으로 이름을 다시 입력합니다.

이 기록은 수업 활동 확인용입니다. 학생이 입력한 이름을 인증하지 않으며
공개 웹 게임에서 제출하는 점수를 시험용 성적처럼 위변조 방지하지는 않습니다.

Apps Script 코드를 바꿀 때는 배포 관리에서 새 버전으로 갱신합니다.
동일한 배포를 갱신하면 게임의 endpoint 주소는 그대로 사용할 수 있습니다.
웹 앱 공식 안내: https://developers.google.com/apps-script/guides/web
