# 모덕 우리말 유람

6학년 2학기 국어 4단원, 여섯 개 HTML 학습 자료를 한옥마을 지도에서 진행하는 게임입니다.

**[학생용 게임 시작하기](https://junho1-commits.github.io/modeok-korean-village/)**

- 여행에 사용할 자료를 선택하면 미션 순서가 무작위로 정해집니다.
- 미션을 끝까지 풀어 정답률 90% 이상을 얻어야 다음 관문이 열립니다.
- 라이프는 3개이며 미션 통과 실패 시 1개 줄어듭니다.
- 라이프가 0개이면 현재 관문을 복습해 90% 이상을 얻어 회복한 다음 정식 도전에 참여합니다.
- 같은 기기와 브라우저 프로필에서 도장, 라이프, 풀이 기록을 이어 갈 수 있습니다.
- 학생 이름은 필수입니다. 연결 설정 후 미션을 마칠 때마다 이름·점수·진행 상황을 교사의 비공개 Google Sheets에 기록합니다.
- 인터넷이 끊기면 전송 대기 기록을 기기에 보관하고 다시 접속할 때 재전송합니다. 실제 저장 확인을 받아야 대기 기록을 지웁니다.
- 구글 연결 설치 방법은 [구글시트_연결안내.txt](구글시트_연결안내.txt)를 참고하세요.

학생은 저장소 파일 대신 GitHub Pages로 공개된 게임 주소에 접속하면 됩니다.

## 로컬 실행

Node.js가 설치된 환경에서 다음 명령으로 실행합니다.

```sh
node serve.cjs
```

브라우저에서 http://127.0.0.1:4173/ 을 엽니다.

## 검증

```sh
node --test tests/*.test.cjs
```

게임 규칙, 통과 경계값, 관문 잠금, 라이프 회복, 6개 학습 자료의 실제 결과 함수와 중간 기록 복원을 검사합니다.

상세 사용법은 [사용안내.txt](사용안내.txt), 외부 라이브러리 고지는 [THIRD-PARTY.txt](THIRD-PARTY.txt)를 참고하세요.
