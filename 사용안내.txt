모덕 우리말 유람 · 한옥마을 모험

학생용 접속 주소: https://junho1-commits.github.io/modeok-korean-village/
GitHub 저장소: https://github.com/junho1-commits/modeok-korean-village

1. 웹에 올리기
압축파일의 내용을 풀어서 index.html, game.js, game-core.js, style.css,
mission-bridge.js, score-config.js, score-sync.js, assets/, missions/, vendor/를 같은 구조로 올리세요.
Netlify, GitHub Pages, Cloudflare Pages 등 정적 웹 호스팅에서 실행됩니다.
게임은 정적 호스팅에서 실행합니다. 점수 기록은 교사의 Google Sheets와 Apps Script 웹 앱을 연결합니다.
학생에게는 index.html이 있는 사이트 주소를 안내하세요.
미션 HTML만 따로 열면 지도와 점수 연동이 되지 않습니다.

2. 게임 규칙
- 출발 화면에서 사용할 원본 HTML 미션을 선택할 수 있습니다. 기본은 6개 전체입니다.
- 각 학생의 여행이 시작될 때 미션 순서를 무작위로 섞고, 해당 순서를 저장합니다.
- 현재 미션을 끝까지 풀어 정답률 90% 이상을 얻으면 다음 미션이 열립니다.
- 정답 개수/전체 문제 수로 판정합니다. 반올림한 점수나 엽전 보너스는 쓰지 않습니다.
  예: 10문제는 9개 이상, 15문제는 14개 이상, 25문제는 23개 이상 정답.
- 라이프는 3개로 시작합니다. 미션 통과 실패 1회당 1개 줄어듭니다.
  개별 문항 하나를 틀렸다는 이유로 라이프가 줄어들지는 않습니다.
- 라이프가 0개면 현재 미션의 회복 복습만 가능합니다.
  회복 복습에서 90% 이상을 얻으면 라이프 3개가 회복됩니다.
  회복 복습은 도장을 주지 않으며, 회복 후 같은 관문에 정식 도전해야 합니다.
- 이미 통과한 관문은 자유 복습이 가능합니다. 자유 복습은 라이프와 도장에 영향을 주지 않습니다.
- 모든 미션을 통과하면 완주 수첩을 텍스트 파일로 내려받을 수 있습니다.

3. 이어 하기
미션 순서, 도장, 라이프와 풀이 중간 기록을 브라우저에 자동 저장합니다.
같은 크롬북, 같은 크롬 프로필, 같은 사이트 주소에서 이어 할 수 있습니다.
일부 퀴즈는 이미 답한 문항의 피드백 화면 대신 다음 미응답 문항부터 복원합니다.
안전하게 멈추려면 퀴즈 위쪽의 '지도에 저장하고 돌아가기' 버튼을 누르세요.
브라우저를 강제 종료하면 마지막 자동 저장 이후 약 1~2초의 기록이 사라질 수 있습니다.
다른 기기와 자동 동기화되지 않으며, 시크릿 모드나 사이트 데이터 삭제 시 기록이 지워질 수 있습니다.
학생 이름을 필수로 입력합니다. 연결 후 이름과 미션별 점수·진행 상황을 선생님의 비공개 Google Sheets에 기록합니다.
정식 도전, 회복 복습, 자유 복습을 구분하여 모든 완료 결과를 기록합니다. 개별 답안은 보내지 않습니다.
인터넷이 끊기면 기기에 전송 대기 기록을 보관합니다. 실제 저장 확인 전에는 창을 유지하고 재접속해 주세요.
자세한 설정은 구글시트_연결안내.txt를 참고하세요.
여러 학생이 같은 크롬 프로필을 공유하면 하나의 여행 기록을 공유합니다.

4. 원본 자료
상위 학생자료 폴더의 6개 HTML 원본은 수정하지 않았습니다.
missions/에 원본 사본을 만들고 결과 보고와 중간 기록 저장 기능만 연결했습니다.
다음 미션으로 연결되는 통과 판정은 지도 프로그램에서 처리합니다.
각 자료 안의 등급명과 축하 문구는 원본 기준이므로 지도의 '90% 이상' 판정과 다를 수 있습니다.
원본 자료에서 '틀린 문제만 다시 풀기'를 하는 경우 정식 통과로 인정하지 않습니다.

5. 교사용 로컬 미리보기
Node.js가 설치된 컴퓨터에서 이 폴더를 열고 다음 명령을 실행합니다.
  node serve.cjs
그런 다음 크롬에서 http://127.0.0.1:4173/ 주소를 엽니다.
파일을 더블 클릭하는 file:// 방식보다 웹 서버 또는 웹 호스팅 실행을 권장합니다.
테스트: node --test tests/*.test.cjs
원본 변경 후 연동 사본 재생성: node build-missions.cjs
재생성 명령은 원본 6개 HTML이 현재 폴더의 바로 위에 있을 때 사용할 수 있습니다.

6. 캐릭터와 지도
첨부한 학교 캐릭터를 기준으로 내장 image_gen으로 만든 여행자 PNG를 사용했습니다.
최종 자산: assets/travelers.png
변형 내용: 꽃 머리장식·땋은 머리와 산 모양 모자·학교 상징을 유지하고,
한옥마을 여행에 맞는 작은 여행 가방과 걷는 자세로 표현했습니다.
제작 프롬프트: 캐릭터_제작프롬프트.txt
한옥마을 지도는 프로그램 내부 SVG로 그려 배치와 이동 경로를 제어합니다.

7. 검증
게임 규칙, 90% 경계값, 잠금, 라이프 회복, 중복 결과 방지, 저장 복원,
6개 원본의 실제 결과 함수와 중간 기록 복원을 자동 테스트합니다.
브라우저에서도 실제 퀴즈 90% 통과, 미통과 라이프 감소, 중간 풀이 복원을 확인했습니다.
업로드 후에는 실제 학생용 주소에서 한 번 더 열어 호스팅 파일 경로를 확인하세요.
